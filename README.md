# 个人主页

基于 Academic Pages 和 Jekyll，发布目标为 https://yangweijun614-droid.github.io。

- `_config.yml` 管理站名、个人资料和网址。
- `_data/navigation.yml` 管理顶部菜单。
- `_pages/about.md`、`_pages/projects.md`、`_pages/notes.md` 和 `_pages/cv.md` 对应四个页面。

在 GitHub 仓库的 **Settings → Pages** 中选择 **GitHub Actions** 作为发布来源。之后提交到 `main` 或 `master` 会触发部署，也可以在 **Actions** 手动运行部署。
