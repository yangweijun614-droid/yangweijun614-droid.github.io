**专业技能**

- 后端开发：用 FastAPI 封装 Python 接口，做请求参数校验和流式响应，通过 Docker 交付运行环境。
- RAG 检索：用 Milvus 做 BM25 与向量召回，按权限过滤和重排，生成端附出处并处理证据不足的请求。
- Agent 编排：用 LangGraph 管理分支和会话状态。Function Calling 生成工具参数，MCP 对接业务工具。
- 应用评测：用固定评测集分别检查检索召回、引用正确性和工具执行结果，通过日志定位失败环节。
- 推理压测：固定负载和并发，统计首 Token 延迟、端到端 P95 和成功 QPS（每秒成功请求数）。

**个人优势**

- 工程落地能力：熟悉 FastAPI、Docker、Milvus、LangGraph 等工具链，能独立完成从接口封装到检索、Agent 编排的端到端实现。
- 评测意识强：习惯用固定评测集和量化指标（Recall@5、引用正确率、工具调用成功率、P95 延迟等）验证效果，善于通过日志定位失败环节。
- Agent 与 RAG 方向聚焦：在混合召回、重排、权限过滤、Function Calling、MCP 工具对接等方面有项目实践，关注证据不足时的拒答与引用可追溯性。
- 学习与协作：具备快速学习新模型与框架的能力，注重文档化与可复现实验，便于团队协作与迭代。
