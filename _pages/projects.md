## 企业知识库与审批查询 Agent

技术栈：Qwen3-8B（拟选）、vLLM、LangGraph、Milvus、BGE Reranker、MCP、FastAPI

项目背景：面向报销场景，提供带条款出处的制度问答，并查询本人单据的审批进度。

1. 按条款切分并保留版本。BM25 和向量检索均按访问权限过滤，再融合结果并重排。
2. 保存会话状态并追问缺失单号。通过 MCP 调用只读查询工具，由业务服务校验单据访问权限。
3. 检查引文能否支持答案及无答案题的拒答。工具调用成功率按符合预期的调用数除以总调用数。

评测口径：Recall@5 逐题用前五条命中数除以已标注相关条款数，再取平均。两种检索使用同一题集。

详细设计：[架构与权限设计](/architecture/)

## Code Agent 与回归评测

技术栈：Python、LangGraph、Qwen3-8B（拟选）、Git、pytest、Docker

项目背景：面向内部 Python 服务的小型变更，生成候选补丁和测试报告，交由研发人员复核。

1. 固定代码基线，以任务描述、源代码和公开测试构建上下文，输出候选补丁。
2. 用 Agent Harness 管理隔离测试、修订上限和日志，保存补丁及 pytest 退出状态。

评测口径：固定模型、题集与代码基线，对比单轮生成和测试反馈修订。通过原有及独立验收测试才算成功。
